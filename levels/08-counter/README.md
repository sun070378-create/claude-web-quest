# 第 8 關：喝水計數器 💧

> 程式最厲害的地方，是它可以「記住」東西，還會「做判斷」。

## 這關會學到

- 用 `let` 建立會改變的**變數**
- 用 `if` 做**判斷**
- 一個網頁裡有好幾個按鈕，各自做不同的事
- （額外）用 `function` 把重複的程式包起來

## 觀念小抄

### 變數

```js
let count = 0;        // 建立一個叫 count 的變數，一開始是 0
count = count + 1;    // 把 count 加 1（右邊算完，再放回左邊）
```

- `const`：放進去就不換了（例如找到的按鈕）
- `let`：之後還會改變（例如杯數）

### 判斷

```js
if (count > 0) {
  // 只有 count 大於 0 時，才會執行這裡
  count = count - 1;
}
```

常用的比較：`>` 大於、`<` 小於、`>=` 大於等於、`===` 等於

### 把數字顯示到畫面上

改變數只是改了「程式腦袋裡的數字」，畫面不會自己變，要記得：

```js
countText.textContent = count;
```

## 任務

打開 `start.html`，按鈕和變數都幫你準備好了：

1. 「＋」讓數字加 1
2. 「－」讓數字減 1
3. 「歸零」讓數字變 0
4. 數字不能小於 0

## 額外挑戰

- 杯數到 8 杯時，用 `if` 讓數字變成綠色。
- 把「更新畫面」寫成一個 `function updateScreen() { … }`，三個按鈕都呼叫它。
