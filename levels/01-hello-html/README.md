# 第 1 關：說聲哈囉 👋

> 每個網頁冒險都從一句「哈囉」開始。

## 這關會學到

- 網頁的基本骨架：`<html>`、`<head>`、`<body>`
- 第一批標籤：`<title>`、`<h1>`、`<p>`、`<strong>`

## 觀念小抄

HTML 用**標籤**把內容包起來，告訴瀏覽器「這是什麼」：

```html
<h1>這是大標題</h1>
<p>這是一段文字，裡面可以有<strong>粗體字</strong>。</p>
```

- 大部分標籤都是**一對**的：`<p>` 開頭、`</p>` 結尾（結尾多一條斜線 `/`）。
- `<head>` 裡放「給瀏覽器看的設定」，畫面上看不到。
- `<body>` 裡放「畫面上看得到的內容」。
- `<h1>` 到 `<h6>` 是標題，數字越小越大、越重要。

## 任務

打開 `start.html`，照著裡面的中文註解完成：

1. 把 `<title>` 改成你自己的標題
2. 寫一個 `<h1>` 大標題
3. 寫至少兩個 `<p>` 段落
4. 用 `<strong>` 把幾個字變粗體

## 怎麼知道過關了？

用瀏覽器打開 `start.html`，右下角的**檢查面板**會列出每個條件。
全部變成 ✅ 就過關了！🎉

卡關了嗎？可以偷看 `answer.html`（參考解答）。

## 額外挑戰（不影響過關）

- 試試 `<h2>`、`<h3>`，看看大小有什麼不同。
- 試試 `<em>斜體</em>`。
