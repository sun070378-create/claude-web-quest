## 觀念小抄

### dataset：把資料藏在元素身上

```js
const card = document.createElement("button");
card.dataset.symbol = "🍎";      // HTML 會變成 <button data-symbol="🍎">

card.dataset.symbol;             // "🍎"：之後就能拿出來比對
```

### 遊戲的流程

```
點一張牌
  ├─ 被鎖住、已經翻開、已經配對？ → 什麼都不做
  ├─ 翻開它
  ├─ 是第一張？ → 記住它，等第二張
  └─ 是第二張？ → 步數 +1
        ├─ 圖案一樣 → 兩張都 matched，配對數 +1
        │              └─ 8 組都配對了？ → 顯示「恭喜過關！」
        └─ 圖案不一樣 → 鎖住，0.8 秒後蓋回去，解鎖
```

**先在紙上把流程想清楚，再開始寫程式**，是寫遊戲最重要的技巧。

### 為什麼需要 lock？

兩張不一樣的牌翻開後，要等 0.8 秒才蓋回去。如果這段時間又點了第三張，狀態就會亂掉。
所以這段時間用 `lock = true` 把遊戲「鎖住」。

## 任務

打開 `start.html`，洗牌函式和狀態變數都幫你準備好了：

1. `createBoard()` 做出 16 張牌
2. 點牌會翻開
3. 翻兩張：步數 +1，一樣的就配對成功
4. 不一樣的過一下蓋回去
5. 全部配對完顯示「恭喜過關！」
6. 「重新開始」按鈕

建議順序：先完成 1、2，看到牌能翻開；再做 3、4；最後 5、6。

> 💡 裁判會自己玩好幾局來測試，需要幾秒鐘，請耐心等一下。
