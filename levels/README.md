# 🗺️ 網頁闖關：從零開始學做網頁

一共 **10 關**，從最基本的 HTML 標籤開始，到用 JavaScript 做出一個待辦清單。
每一關都有**自動檢查面板**，完成條件就會打勾 ✅，全部打勾就過關 🎉。

## 開始之前：準備工具

1. **下載這個專案到電腦**
   在 GitHub 專案頁面按綠色的 **Code** 按鈕 → **Download ZIP**，下載後解壓縮。
2. **安裝文字編輯器**
   推薦免費的 [VS Code](https://code.visualstudio.com/)。打開後，選「檔案 → 開啟資料夾」，選剛剛解壓縮的資料夾。
3. **用瀏覽器打開關卡地圖**
   找到 `levels/index.html`，用滑鼠雙擊，就會在瀏覽器裡打開。

## 怎麼玩？

每一關的資料夾裡都有這些檔案：

| 檔案 | 用途 |
|------|------|
| `README.md` | 📖 這關的說明：會學到什麼、觀念小抄、任務 |
| `start.html` | ✏️ **你要修改的練習檔** |
| `answer.html` | 🔑 參考解答（卡關時再看） |
| `check.js` | 🤖 裁判，負責檢查你有沒有過關（不用改） |

每一關的流程：

1. 先讀 `README.md`（在 VS Code 裡打開後按 `Ctrl + Shift + V` 可以看漂亮的預覽，Mac 是 `Cmd + Shift + V`）
2. 用 VS Code 打開 `start.html`，照著裡面的中文註解寫程式
3. **存檔**（`Ctrl + S`，Mac 是 `Cmd + S`）
4. 用瀏覽器打開 `start.html`（或回到瀏覽器按**重新整理**）
5. 看右下角的檢查面板：⬜ 是還沒完成，下面的 💡 是提示
6. 全部 ✅ 就過關！面板會出現「前往下一關」的連結

> 💡 檢查面板擋到畫面時，點它的黃色標題列就能收起來。

建議一天玩 1～2 關，每關大約 15～30 分鐘。

## 卡關了怎麼辦？

- 看檢查面板上的 💡 提示
- 重讀 README 的「觀念小抄」
- 按 `F12` 打開開發者工具，看「Console（主控台）」有沒有紅色錯誤訊息
- 偷看 `answer.html`，看懂之後**關掉它，自己再寫一遍**，這樣學得最快
- 把程式碼貼給 Claude 問：「我哪裡寫錯了？」

## 常見錯誤 Top 5

1. **忘記存檔**就去重新整理
2. 標籤沒有成對：`<p>` 忘了寫 `</p>`
3. CSS 少了 `;` 或 `}`
4. JavaScript 大小寫打錯：`queryselector` ✗ → `querySelector` ✓
5. 用了全形符號：`（`、`；`、`"` 都要用**半形**（英文輸入法）
