# 第 23 關：每個人都能用 ♿

> 不是每個人都用同樣的方式上網：有人看不到螢幕，靠「螢幕報讀軟體」把網頁唸出來；有人手不方便，只能用鍵盤；有人視力不好、有人在大太陽下看手機……
> **無障礙設計**（Accessibility，簡稱 a11y）就是讓網頁**每個人都能用**。

## 這關會學到

- `lang` 屬性
- 圖片的 `alt`
- `<label>` 為什麼不能只用 placeholder
- 為什麼按鈕一定要用 `<button>`
- 文字顏色的**對比度**

## 觀念小抄

### 好消息：用對標籤，就做好一大半了

| 問題 | 做法 |
|------|------|
| 報讀軟體不知道要用什麼語言唸 | `<html lang="zh-Hant-TW">` |
| 看不到圖片的人不知道圖在畫什麼 | `<img alt="圖片的說明">`；純裝飾的圖寫 `alt=""` |
| 輸入框不知道要填什麼 | 每個輸入框都配一個 `<label>` |
| 鍵盤選不到、報讀軟體不知道能按 | 能按的東西用 `<button>`，要跳到別頁的用 `<a>` |
| 字太淡看不清楚 | 文字和背景的對比至少 **4.5 : 1** |

### 為什麼不能用 div 當按鈕？

`<div>` 只是一個「盒子」，瀏覽器不知道它能按：

- 用鍵盤按 `Tab`，**跳不到**它
- 報讀軟體**不會**說「這是按鈕」

`<button>` 天生就會這些，什麼都不用多寫。

### 自己體驗看看

1. **只用鍵盤**：把滑鼠放旁邊，一直按 `Tab`，看看能不能選到每個輸入框和按鈕，按 `Enter` 能不能報名。分別在 `start.html` 和 `answer.html` 試試看，差很多！
2. **檢查對比**：按 `F12`，用左上角的箭頭點一段文字，在「Styles」裡點顏色的小方塊，會顯示「Contrast ratio（對比度）」。
3. **Lighthouse 健檢**：開發者工具裡有一個「Lighthouse」分頁，按「Analyze page load」，它會幫你的網頁打一個無障礙分數。

## 任務

打開 `start.html`，修好 5 個問題：

1. `<html>` 加上 `lang`
2. 圖片加上 `alt`
3. 輸入框加上 `<label>`
4. `<div>` 按鈕改成 `<button>`
5. 說明文字換深一點的顏色
