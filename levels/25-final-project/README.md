## 過關條件：上線前檢查清單

不管你做什麼作品，檢查面板會確認這些「好網頁的基本功」：

1. 網頁標題改成你的作品名稱
2. 有 `<header>`、`<main>`、`<footer>` 和 `<h1>`
3. 樣式寫在 `style.css`（第 22 關）
4. 程式寫在 `script.js`（第 22 關）
5. 有可以互動的按鈕或輸入框
6. 沒有任何錯誤（第 21 關）
7. 圖片有 `alt`、輸入框有 `label`（第 23 關）
8. 沒有左右捲軸

另外有一項裁判沒辦法自動檢查（在電腦上直接打開檔案時，瀏覽器不讓裁判讀 `style.css` 的內容），請你**自己確認**：

- [ ] **手機上也好看**：按 `F12` →「手機」圖示，選一支手機看看（第 6 關）

## 規劃步驟

1. **在紙上畫出來**：畫面上有哪些區塊？按下按鈕會發生什麼事？
2. **先寫 HTML**：把內容都放上去，先不管好不好看
3. **再寫 CSS**：排版、顏色、手機版
4. **最後寫 JS**：一次加一個功能，加完就重新整理測試
5. **對照檢查清單**：把檢查面板的 ⬜ 都變成 ✅

## 讓它上線

做完之後，用第 24 關學到的方法，把你的作品放上 GitHub：

1. 在 GitHub 專案頁面，進到 `levels/25-final-project/`
2. 按 **Add file** → **Upload files**，把你的 `start.html`、`style.css`、`script.js` 拖進去
3. Commit 到新分支 → 開 Pull Request → 合併
4. 等 1～2 分鐘，就能在這裡看到你的作品：
   `https://sun070378-create.github.io/claude-web-quest/levels/25-final-project/start.html`

把網址傳給朋友看吧！🎉
