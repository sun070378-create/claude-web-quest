# claude-web-quest

Jason 學做網頁的練習紀錄，也是 Jason 放作品的地方。全部用 [Claude Code](https://claude.com/claude-code) 一起完成。

- 🏠 **個人網頁**：<https://sun070378-create.github.io/claude-web-quest/>
- 🎮 **網頁闖關**：<https://sun070378-create.github.io/claude-web-quest/levels/>

## 裡面有什麼

| 位置 | 內容 |
|------|------|
| `index.html`、`works.js` | 個人網頁。作品清單寫在 `works.js` 裡 |
| [`levels/`](levels/) | 「網頁闖關」：25 關，從第一個 HTML 標籤一路學到 JavaScript 和 GitHub，每一關都有自動檢查面板 |
| [`guides/`](guides/) | 說明文件：[個人網頁修改說明](guides/edit-homepage.md)、[GitHub Desktop 新手教學](guides/github-desktop.md) |

所有網頁都是純 HTML、CSS、JavaScript，不需要安裝任何東西，下載後用瀏覽器打開就能用。

## 給路過的你

這是 Jason 自己的練習紀錄，「網頁闖關」也是照 Jason 的進度設計的。
想從零學網頁的話，[MDN Web Docs](https://developer.mozilla.org/zh-TW/)、[freeCodeCamp](https://www.freecodecamp.org/) 這些更完整的資源會更適合你。

不過歡迎參考這裡的內容！如果你也想玩這套關卡，或有任何問題，歡迎到 [Issues](https://github.com/sun070378-create/claude-web-quest/issues) 留言告訴我。
